Number Series – Pre‑Class Warm‑up (Missing &amp; Wrong)
===================================================

Based on: old 2025 PDFs – &quot;Number Series Basic and Types&quot;, &quot;Missing Number Series&quot;, &quot;Wrong Number Series&quot;

Goal (20–25 min before LIVE class)
----------------------------------
- Common patterns की याद ताज़ा करना:
  - +/− constant, +/− increasing
  - × / ÷   patterns
  - squares, cubes, prime, mixed
- ताकि class में teacher के नए questions जल्दी समझ में आयें।


Block–1: Missing Number (Basic Patterns) – 10 Q
-----------------------------------------------

Find the missing term ( ? ):

1)  3, 7, 11, 15, ?  
2)  5, 10, 20, 40, ?  
3)  2, 5, 10, 17, 26, ?  
4)  1, 4, 9, 16, ?, 36  
5)  2, 6, 12, 20, 30, ?  

6)  4, 9, 19, 39, ?, 159  
7)  3, 6, 12, 24, 48, ?  
8)  7, 14, 28, 56, ?, 224  
9)  11, 13, 17, 19, 23, ?  
10)  1, 2, 6, 24, ?, 720  

Try to identify pattern logically, फिर नीचे answers से verify करो।


Block–2: Wrong Number – 5 Q
---------------------------

In each series, find which term is wrong:

11)  4, 8, 16, 24, 32, 64  
12)  2, 5, 11, 23, 47, 95  
13)  3, 9, 27, 81, 162, 243  
14)  5, 10, 21, 43, 86, 172  
15)  7, 14, 21, 28, 36, 42  

Check pattern:
- कभी common difference देखें,
- कभी ratio देखें (×2, ×3, etc.),
- कभी &quot;×2 + 1&quot;, &quot;×3 − 2&quot; जैसे mix operations।


Block–3: Mixed Concept Drill – 5 Q
----------------------------------

Identify pattern type (just name it):

16)  2, 6, 12, 20, 30, 42, ...  
17)  1, 8, 27, 64, 125, ...  
18)  2, 3, 5, 7, 11, 13, ...  
19)  100, 90, 81, 73, 66, ...  
20)  6, 12, 24, 48, 96, ...  

Write:
- Pattern name (AP, GP, squares, cubes, primes, etc.)
- Next term (if possible).


Answer Key (Self‑check)
-----------------------

Missing Numbers:
1) 19  (difference +4)  
2) 80  (×2)  
3) 37  (add 3,5,7,9,11...)  
4) 25  (squares: 1,4,9,16,25,36)  
5) 42  (add 4,6,8,10,12...)  

6) 79  (×2 −1 pattern: 4,9,19,39,79,159)  
7) 96  (×2)  
8) 112 (×2)  
9) 29  (primes)  
10) 120 (factorial: 1,2,6,24,120,720)  

Wrong Numbers:
11) Wrong term = 24  
    (pattern should be ×2: 4,8,16,32,64; 24 doesn&apos;t fit)  

12) Correct pattern: ×2 +1 → 2,5,11,23,47,95 (actually all correct – trick Q)  

13) Wrong term = 162  
    (pattern ×3: 3,9,27,81,243,... 162 गलत है)  

14) All terms follow ×2 −1,×2+1 alternately?  
    5,10,21,43,86,172 → actually all correct (5×2=10; 10×2+1=21; 21×2+1=43; 43×2=86; 86×2=172)  

15) Wrong term = 36  
    (AP +7: 7,14,21,28,35,42; 36 गलत है)  

Mixed Concept:
16) Pattern: n(n+1) → 2,6,12,20,30,42 (quadratic difference +2,+4,+6...)  
17) Cubes: 1³, 2³, 3³, 4³, 5³ → next 6³ = 216  
18) Primes sequence → next 17  
19) Decreasing with differences: −10, −9, −8, −7 → next −6 → 60  
20) GP ×2 → next 192  


How to Use
----------

- LIVE से पहले:
  - Block–1 के 10 missing number series अवश्य करो (10–12 min).
  - Block–2 या Block–3 में से कोई एक (5 Q) कर लो (5–7 min).
- Pattern में अटक जाओ तो solution देखकर pattern &quot;नाम से&quot; याद करो:
  - &quot;+4 series&quot;, &quot;×2 series&quot;, &quot;factorial type&quot;, &quot;prime series&quot; आदि।
- Class के बाद:
  - अगर teacher किसी special pattern पर ज़्यादा examples देता है, उसी pattern को इस warm‑up में next दिन extra बार दोहराओ।
