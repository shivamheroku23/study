Quadratic Equations – Pre‑Class Warm‑up
=======================================

Based on: old 2025 PDFs – &quot;Quadratic Equations (Basics, Finding Roots, Comparison, Practice)&quot;

Goal (20–25 min before LIVE class)
----------------------------------
- Recall:
  - Standard form of quadratic
  - Discriminant (D = b² − 4ac)
  - Roots formula
  - Sign/range of roots without full calculation


Block–1: Basics &amp; Standard Form – 5 Q (5 min)
---------------------------------------------

1) Write the standard form of a quadratic equation in x.  
2) For each, identify a, b, c:

   (i)  2x² + 5x − 3 = 0  
   (ii) 3x² − 7x + 2 = 0  
   (iii) x² − 4x − 12 = 0  

3) Convert to standard form:

   (i)  x(x + 5) = 6  
   (ii)  (x − 3)(x + 2) = 0  

Answers:
- Standard form: ax² + bx + c = 0  
- (i) a=2, b=5, c=−3  
- (ii) a=3, b=−7, c=2  
- (iii) a=1, b=−4, c=−12  

- x(x + 5) = 6 → x² + 5x − 6 = 0  
- (x − 3)(x + 2) = 0 → x² − x − 6 = 0  


Block–2: Roots Using Formula / Factorisation – 5 Q (10 min)
-----------------------------------------------------------

Solve for x:

4)  x² − 5x + 6 = 0  
5)  x² + 7x + 10 = 0  
6)  2x² − 3x − 2 = 0  
7)  3x² + x − 2 = 0  
8)  x² − 9 = 0  

(Use: factorisation or formula x = [−b ± √(b² − 4ac)] / (2a))

Answers:
4) (x−2)(x−3)=0 → x = 2,3  
5) (x+5)(x+2)=0 → x = −5,−2  
6) 2x² − 3x − 2 = 0 → (2x+1)(x−2)=0 → x = 2, −1/2  
7) 3x² + x − 2 = 0 → (3x−2)(x+1)=0 → x = 2/3, −1  
8) x² − 9 = 0 → (x−3)(x+3)=0 → x = 3, −3  


Block–3: Discriminant &amp; Nature of Roots – 5 Q (5–7 min)
---------------------------------------------------------

For each quadratic, find D = b² − 4ac and nature:

9)  x² − 4x + 4 = 0  
10) x² + 5x + 6 = 0  
11) 4x² + 4x + 1 = 0  
12) x² + 2x + 5 = 0  
13) 2x² − 5x + 2 = 0  

Rules:
- D &gt; 0 → real &amp; distinct roots  
- D = 0 → real &amp; equal roots  
- D &lt; 0 → no real roots (complex)  

Answers:
9) D = (−4)² − 4·1·4 = 16 − 16 = 0  → real &amp; equal  
10) D = 25 − 24 = 1 &gt;0 → real &amp; distinct  
11) D = 16 − 16 = 0 → real &amp; equal  
12) D = 4 − 20 = −16 &lt;0 → no real roots  
13) D = 25 − 16 = 9 &gt;0 → real &amp; distinct  


Block–4: Comparison / Sign of Roots – 5 Q (5–7 min)
---------------------------------------------------

Without fully solving, decide sign of roots:

14) x² − 5x + 6 = 0  
15) x² + 5x + 6 = 0  
16) x² − 3x − 4 = 0  
17) 2x² + 3x + 1 = 0  
18) x² − x + 1 = 0  

Hint:
- Sum of roots = −b/a  
- Product of roots = c/a  
- If product &gt; 0 and sum &gt; 0 → दोनों positive  
- If product &gt; 0 and sum &lt; 0 → दोनों negative  
- If product &lt; 0 → one positive, one negative  
- If D &lt; 0 → no real roots  

Answers (sign only):
14) Sum = 5 &gt;0, Product = 6 &gt;0 → दोनों positive  
15) Sum = −5 &lt;0, Product = 6 &gt;0 → दोनों negative  
16) Sum = 3 &gt;0, Product = −4 &lt;0 → one +, one −  
17) Sum = −3/2 &lt;0, Product = 1/2 &gt;0 → दोनों negative  
18) D = 1 − 4 = −3 &lt;0 → no real roots  


How to Use
----------

- LIVE से पहले:
  - Block–1 + Block–2 अवश्य करो (basics + 5 questions).
  - अगर time हो तो Block–3 भी (D और nature).
- Class में teacher जब भी नया type सिखाए (comparison of roots, range of quadratic, inequality),  
  - अगली बार warm‑up में Block–4 को पहले दोहराओ।
