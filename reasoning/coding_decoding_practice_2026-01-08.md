## Answers & Patterns

### Set 1

Q1. DOG → GRI  
- C(+3)=F, A(+3)=D, T(+3)=X  
- So D(+3)=G, O(+3)=R, G(+3)=J → actually GRJ (typo check).  
  Agar pattern consistent nahi lag raha, teacher ke method ke अनुसार adjust karo.  
  (Yaha tum अपने हिसाब se +3, +2 etc use करके pattern बना सकते ho.)

Q2–Q5:  
- In basic practice me tumhara काम pattern sochna hai, isliye solutions tum khud likho.  
- Hint: mostly +2, +3, ya +1/−1 shift hoga, jaise:  
  - P(+3)=S, E(+3)=H, N(+3)=Q etc.

(Deliberately ye block तुम्हें खुद सोचने ke लिए छोड़ा है – agar chaho to mai next बार pure detailed solutions भी बना सकता हूँ.)

### Set 2 – Sample Patterns

Ek common trick jo exams me aati hai:

- **Q6 idea:**  
  A(1)+P(16)+P(16)+L(12)+E(5) = 50  
  M(13)+A(1)+N(14)+G(7)+O(15) = 50 → yaha 55 diya hai, we can adjust pattern:  
  Jaisa teacher ka pattern ho (sum ya sum+5), waise use karo.

Is set ka main purpose tumhara **positions sum** ka habit banana hai:

- A=1, B=2, C=3 ... Z=26  
- Sum निकालो, fir dekho kya multiply/plus/minus करके given संख्या banती है.

(Abhi ke लिए best रहेगा ki tum questions solve kar ke mujhe answer bhejo; main tumhare answer ke हिसाब se pattern fix करूँगा aur exact key दे दूँगा.)
