Core Idea (Class 1)
-------------------
- Fast addition by:
  - Grouping tens and units separately.
  - Carry handling in mind (not writing intermediate steps).
  - Keeping numbers aligned mentally (place value sense).
- Same logic extends to:
  - Bigger numbers (3-digit, 4-digit, 5-digit…)
  - Decimal numbers (just treat decimal point as place separator).

Step Patterns to Remember
-------------------------

1) 2-digit Addition (AB + CD)
-----------------------------

Example: 47 + 28

Normal:
- Units: 7 + 8 = 15 → write 5, carry 1
- Tens: 4 + 2 + 1 = 7
- Answer: 75

Vedic-style mental steps:
- Think: 40 + 20 = 60
- Units: 7 + 8 = 15 → 60 + 15 = 75
- Or: (7+8 = 15 → 50 + 25 = 75)

2) 3-digit Addition (ABC + DEF)
-------------------------------

Key idea:
- Add hundreds, tens, units separately.
- Carry manage in head.

Example: 562 + 137

- Hundreds: 5 + 1 = 6
- Answer: 699

Example: 714 + 285

4) Addition of 3 numbers (2-digit &amp; 3-digit)
---------------------------------------------

Trick:
- Add tens/units of two numbers first → get intermediate sum.
- Then add the third number.

Example (2-digit): 48 + 27 + 36
- (48 + 27) = 75
- 75 + 36 = 111

Example (3-digit): 316 + 243 + 120
- (316 + 243) = 559
- 559 + 120 = 679

Goal:
- Train mind to do chain addition without writing all steps.


5) Addition with Decimals
-------------------------

Rule:
- Align decimal points in mind.
- Add whole part and decimal part separately.

Example:
- 34.8 + 25.1
  - Whole: 34 + 25 = 59
  - Decimal: 0.8 + 0.1 = 0.9
  - Answer: 59.9

- 69.3 + 22.7
  - Whole: 69 + 22 = 91
  - Decimal: 0.3 + 0.7 = 1.0
  - Answer: 92.0

Larger:
- 348.7 + 561.4
- 1234.5 + 6789.2
- 902.5 + 107.6
- 9056.7 + 2143.8

6) Subtraction of 2-digit Numbers
---------------------------------

Idea:
- Borrow mentally when needed.
- Or think in complement form.

Example: 78 − 32
- 78 − 30 = 48
- 48 − 2 = 46

Example: 96 − 41
- 96 − 40 = 56
- 56 − 1 = 55
