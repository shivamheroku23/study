Part A – RC using Today&apos;s Skimming Technique
----------------------------------------------

1. Pick 1 RC passage (Bank Pre/Mains level as per comfort).
2. Steps:
   - Read title + first paragraph carefully.
   - Quickly skim the rest (don&apos;t stop on every word).
   - Try to understand:
     - Main idea (in one simple sentence)
     - Author&apos;s tone (positive/negative/neutral/mixed)

3. Then solve all questions:
   - First attempt them **without re-reading whole passage**.
   - Only if confused, go back to specific lines.

4. After finishing:
   - Count:
     - Total questions: __
     - Correct: __
     - Wrong: __
   - For each wrong question, note:
     - (I) = idea गलत समझा
     - (L) = line या detail miss हो गई
     - (O) = option trap में फँसे


Part B – Tenses / Grammar from Recorded Lectures
------------------------------------------------

1. Watch &quot;Tenses – Part 1&quot; (or continue from where you stopped).
2. For each tense covered, write in notebook:
   - Name of tense
   - Use (1 line)
   - 1 correct example
   - 1 common error pattern

Example format:
- Present Simple:
  - Use: daily routine, facts
  - Example: &quot;He goes to school every day.&quot;
  - Error: &quot;He go to school every day.&quot;

3. After watching:
   - Solve 15–20 Error Detection questions focusing on:
     - Tense
     - Subject–Verb Agreement (SVA)

   While checking:
   - Correct: __ / 20
   - Wrong: __ / 20
   - Mark error type:
     - (T) = wrong tense
     - (S) = SVA mismatch
     - (P) = preposition/article/other
