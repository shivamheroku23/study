Core Concepts
-------------

1. **Standard form:**  
   ax² + bx + c = 0  

2. **Discriminant:**  
   D = b² − 4ac  

3. **Roots formula:**  
   x = [−b ± √D] / (2a)  

4. **Sum and Product of roots:**  
   If roots are α, β then  
   - α + β = −b/a  
   - αβ = c/a

Type–1: Finding Roots (Factorisation)
-------------------------------------

सबसे पहले factorise करने की कोशिश:

Example 1: x² − 5x + 6 = 0  
- Need two numbers whose:
  - Sum = −5
  - Product = 6  
- Numbers = −2, −3  

So: x² − 5x + 6 = (x − 2)(x − 3) = 0  
→ x = 2, 3  

Example 2: 2x² − 3x − 2 = 0  
- a = 2, c = −2 → a·c = −4  
- Need numbers whose:
  - Product = −4
  - Sum = −3  
- Numbers = −4, +1  

2x² − 3x − 2 = 2x² − 4x + x − 2  
= 2x(x − 2) + 1(x − 2)  
= (2x + 1)(x − 2)  

Roots: x = 2, −1/2


Type–2: Roots Using Formula (जब factorisation मुश्किल हो)
--------------------------------------------------------

Example 3: 3x² + x − 2 = 0  

a=3, b=1, c=−2  
D = b² − 4ac = 1 + 24 = 25  

x = [−1 ± √25] / (2·3)  
= (−1 ± 5)/6  

Roots:  
- x₁ = (−1 + 5)/6 = 4/6 = 2/3  
- x₂ = (−1 − 5)/6 = −6/6 = −1  


Type–3: Nature of Roots (बिना solve किये)
-----------------------------------------

Use D:

- D &gt; 0  → real &amp; distinct  
- D = 0  → real &amp; equal (repeated root)  
- D &lt; 0  → no real roots (complex)

Example 4: x² − 4x + 4 = 0  
- a=1, b=−4, c=4  
- D = 16 − 16 = 0 → real &amp; equal roots  

Example 5: x² + 2x + 5 = 0  
- a=1, b=2, c=5  
- D = 4 − 20 = −16 → no real roots

Type–4: Sign / Nature of Roots using Sum &amp; Product
----------------------------------------------------

Without full solution, सिर्फ sign (positive/negative/mixed) निकालना।

Rules:
- Sum S = −b/a  
- Product P = c/a  

1. If P &gt; 0 and S &gt; 0 → दोनों positive  
2. If P &gt; 0 and S &lt; 0 → दोनों negative  
3. If P &lt; 0 → एक positive, एक negative  
4. If D &lt; 0 → real root ही नहीं

Example 6: x² − 5x + 6 = 0  
- S = 5 &gt; 0  
- P = 6 &gt; 0  
→ दोनों roots positive  

Example 7: x² + 5x + 6 = 0  
- S = −5 &lt; 0  
- P = 6 &gt; 0  
→ दोनों negative  

Example 8: x² − 3x − 4 = 0  
- S = 3 &gt; 0  
- P = −4 &lt; 0  
→ एक positive, एक negative  


Type–5: Comparison of Roots (बिना exact value)
----------------------------------------------

Old PDFs में sir ये pattern ज़्यादा करवाते हैं:

- Compare roots of  
  ax² + bx + c = 0  and  px² + qx + r = 0  

Use:
- Nature (D)  
- Sum &amp; product  
- Sometimes inequality tricks.

Simple example idea:

If we know for equation E1:
- both roots are positive and less than 5  
and for E2:
- both roots are positive and greater than 5  

Then any root of E2 &gt; any root of E1.

Sir&apos;s Style – Summary (Quadratics)
-------------------------------------

1. **Always try factorisation first.**  
   - Small integer roots → easiest.  

2. If factorisation नहीं दिख रहा:  
   - Use discriminant + formula.  

3. Sign of roots:  
   - Sum/Product से निकालो, full solve की ज़रूरत नहीं।  

4. For practice:  
   - Same equation को तीन तरह से समझो:
     - Factorisation,
     - Formula,
     - Sum/Product + D discussion.
