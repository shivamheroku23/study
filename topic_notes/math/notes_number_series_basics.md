Number Series – Basics &amp; Sir&apos;s Method (Notes)

Source idea: old 2025 PDFs – &quot;Number Series Basic and Types&quot;, &quot;Missing Number Series Part 1–3&quot;, &quot;Wrong Number Series&quot;.

Question Types
--------------

1) **Missing Number Series**  
   - You have to find &quot;?&quot; in the series.

   Example: 3, 7, 11, 15, ?  

2) **Wrong Number Series**  
   - One term is incorrect; identify it.

   Example: 4, 8, 16, 24, 32, 64  

3) **Mixed Types**  
   - Including:
     - +constant, +increasing difference  
     - ×constant, ×with addition/subtraction  
     - squares/cubes  
     - prime numbers  
     - factorial, etc.


Sir&apos;s General Steps (Missing Series)
---------------------------------------

**Step 1 – Check Difference (First 3–4 terms)**

Example 1:  
3, 7, 11, 15, ?  

Differences: +4, +4, +4 → constant  
Pattern: add 4 each time → next = 19  

Example 2:  
2, 5, 10, 17, 26, ?  

Differences: 3, 5, 7, 9 → increasing by 2  
Next difference = 11 → 26 + 11 = 37  

**Step 2 – Check Multiplication / Division**

Example 3:  
5, 10, 20, 40, ?  

Here:
- ×2, ×2, ×2 → next = 40 × 2 = 80  

Example 4:  
7, 14, 28, 56, ?, 224  

Again ×2 pattern → missing term = 112  

**Step 3 – &quot;× plus something&quot; pattern**

Example 5:  
4, 9, 19, 39, ?, 159  

Differences: 5, 10, 20, ?  
Each time difference ×2: 5,10,20,40  
So series: previous term ×2 −  (something small)?  

Check:  
4 → 9 → 4×2 +1=9  
9 → 19 → 9×2 +1=19  
19 → 39 → 19×2 +1 = 39  
39 → ? → 39×2 +1 = 79  
79 → 159 (given)  

So missing = 79  

Pattern: &quot;×2 + 1&quot;.

**Step 4 – Check squares / cubes**

Example 6:  
1, 4, 9, 16, 25, 36  

→ 1², 2², 3², 4², 5², 6²  

Example 7:  
1, 8, 27, 64, 125, ...  

→ 1³, 2³, 3³, 4³, 5³  

**Step 5 – Prime numbers**

Example 8:  
2, 3, 5, 7, 11, 13, 17, ...  

All are primes → next = 19  

Example 9:  
11, 13, 17, 19, 23, ?  

All primes starting from 11 → next = 29  


Sir&apos;s General Steps (Wrong Series)
-------------------------------------

1. First, **assume series is correct** and find its pattern.
2. Where the pattern breaks, that term is wrong.

Example 10:  
4, 8, 16, 24, 32, 64  

Check pattern: looks like ×2 series:  
4, 8, 16, 32, 64 ... (24 doesn&apos;t fit)  

So wrong term = 24  

Example 11:  
7, 14, 21, 28, 36, 42  

Check differences: +7, +7, +7, +8, +6  
Non‑uniform at 36. Correct AP would be:  
7,14,21,28,35,42 → so 36 is wrong term.

Key Pattern Types – Short Summary
---------------------------------

1) **AP (Arithmetic progression):**  
   - Same difference (d):  
     - 3, 7, 11, 15,... (d=4)  

2) **GP (Geometric progression):**  
   - Same ratio (r):  
     - 2, 4, 8, 16,... (r=2)  

3) **AP in differences:**  
   - 2, 5, 10, 17, 26,...  
   - Differences: 3,5,7,9 → AP  

4) **× + k / × − k:**  
   - 4, 9, 19, 39, 79,... → ×2 +1  
   - 3, 7, 15, 31, 63,... → ×2 +1 pattern  

5) **Squares / Cubes:**  
   - 1,4,9,16,25,... (n²)  
   - 1,8,27,64,125,... (n³)  

6) **Prime series:**  
   - 2,3,5,7,11,13,17,...  

7) **Factorial type / double factorial:**  
   - 1,2,6,24,120,720,... (n!)
